# treinamento-proway-tf-app-fidelidade

App de Fidelidade - Trabalho final - Treinamento de Android + Kotlin by Proway

## Objeto do Projeto

Esse projeto tem como objeto demonstrar os novos conhecimentos adquiridos como participantes no marco do Treinamento de Android + Kotlin ministrado pela Proway em parceria com a Capgemini.

## Estrutura do projeto

### Diretórios

O codigo desse projeto consta de:

- backend: diretório onde residem os arquivos para levantar o backend
- outros: diretórios dos arquivos de codigo fonte da app android

### Branches

- __main:__ branch principal onde reside tudo o codigo estável
- __sandbox:__ nessa branch mergeamos as outras branchs nas que trabalhamos para testar a integração, se tudo correr bem, mergeamos para a `main`.
